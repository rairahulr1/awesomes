## 🔍 Search

Use the search bar above or press `Ctrl+K` to search across all repo descriptions and categories.

## 📦 How to Add a New Repo

1. Fork this repository
2. Add a new markdown file in `docs/repos/` following the existing format
3. Include frontmatter: `title`, `url`, `stars`, `category`, `tag`, `description`
4. Push your changes — the site will auto-deploy via GitHub Actions
5. Add an entry to the category grid above

## 💬 Comments

Each repo page includes a comment section powered by [Utterances](https://utterances.app/), tied to a GitHub Issue for discussion.
