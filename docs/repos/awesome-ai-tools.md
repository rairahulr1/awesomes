## Notes

- **Heavily affiliate-linked.** Many entries route through `altern.ai`, `dub.sh` and vendor referral
  parameters. That is not disqualifying, but it means placement tracks commercial relationships as
  much as quality.
- **Half the models listed are obsolete** — GPT-3-era entries (OPT, BLOOM, Gopher, Stable Beluga)
  sit alongside current ones with no curation signal. The model section is not a live index.
- 23 GitHub topics for a list of mostly non-repos. Treat the topical footprint as branding.
- The repo also maintains a separate `IMAGE.md` for image tools; this README links out rather than
  duplicating it.
