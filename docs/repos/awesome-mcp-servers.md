## About this list

A community-maintained catalogue of [Model Context Protocol](https://modelcontextprotocol.io) servers
and integrations. It is the single highest-traffic reference for MCP tooling — useful as a discovery
index even when the linked project is not itself maintained by this repo.

The list ships nine translations of the README (fa-IR, ja, ko, pt-BR, th, zh, zh-TW), which is the
fastest signal that it is actively curated rather than a stale dump.

## Notes on scope

- Entries are links out; this index does not mirror or verify individual servers.
- Because it is community-submitted, server quality varies. Check maintenance activity before
  adopting anything in a production agent.
