About this index

These lists already exist on GitHub. This site indexes them: one page per list, the description exactly as the maintainer wrote it, a star count snapshotted from GitHub, and a link to the original. Nothing is mirrored.

Each page carries its own comment thread. Star counts are point-in-time and will drift — the source link is authoritative.

Source lists are credited and linked; original descriptions are preserved verbatim.
