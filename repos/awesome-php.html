awesome-php ​

A curated list of amazing awesome PHP libraries, resources and shiny things.

Source: github.com/ziadoz/awesome-php · ★ 32.7k · WTFPL · 1,779 commits · the oldest and broadest list in this index

The most complete PHP reference here. Also the closest thing to a community standard: awesome-laravel was explicitly inspired by it.

Notes ​

  • Maintained on master and still receiving commits — but the top of the README carries the original "amazing awesome … shiny things" framing, which dates it.
  • WTFPL is an unusual licence. It is effectively public domain but carries no explicit patent grant — a real consideration if you ship anything derivative commercially.
  • 5.1k forks against 32.7k stars is a healthy ratio, unlike some entries in this index.
